I developed Solid Aphidence, an engaging visual novel that combines mystery storytelling with interactive gameplay elements. This project showcases my skills in Unity development, dialogue system implementation, and creating immersive narrative experiences.

## Game Overview

Solid Aphidence is a mystery visual novel where players take on the role of a detective investigating a mysterious murder case. The game features branching dialogue paths, evidence collection mechanics, and multiple story outcomes based on player choices.

## Key Features

**Interactive Dialogue System**: Implemented a comprehensive dialogue system that allows players to make meaningful choices that affect the story progression and character relationships.

**Evidence Collection**: Created an intuitive evidence collection mechanic where players gather clues throughout the investigation, building their case through careful observation and deduction.

**Multiple Endings**: Designed branching story paths that lead to different conclusions based on player decisions, encouraging replayability and exploration of different narrative possibilities.

**Visual Novel Elements**: Developed traditional visual novel features including character sprites, background art, and text presentation systems that enhance the storytelling experience.

## Technical Implementation

Built using Unity with C#, the game features a modular architecture that allows for easy content expansion and story updates. The dialogue system is designed to be flexible and reusable for future projects.

## Player Experience

The game emphasizes player agency through meaningful choices and consequences. Players must carefully consider their dialogue options and evidence collection strategies to uncover the truth behind the mysterious murder case.

This project demonstrates my ability to create engaging narrative experiences while maintaining technical excellence in game development.
