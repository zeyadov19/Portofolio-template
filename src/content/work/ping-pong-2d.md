I developed Ping Pong 2D using Game Maker Studio, creating a classic arcade-style sports game that demonstrates my proficiency with GML (Game Maker Language) and 2D game development principles.

## Game Overview

Ping Pong 2D is a faithful recreation of the classic table tennis game, featuring smooth ball physics, responsive paddle controls, and engaging gameplay that captures the essence of the original arcade experience.

## Key Features

**Physics System**: Implemented realistic ball physics with proper bouncing mechanics, spin effects, and collision detection that creates authentic ping pong gameplay.

**Responsive Controls**: Designed intuitive paddle controls that respond smoothly to player input, allowing for precise positioning and strategic gameplay.

**Score System**: Created a comprehensive scoring system that tracks points, matches, and provides clear feedback to players about their performance.

**Visual Polish**: Developed clean, appealing visuals with smooth animations and particle effects that enhance the overall gaming experience.

## Technical Implementation

Built entirely with Game Maker Studio and GML, the game showcases my ability to work with different game engines and programming languages. The project demonstrates efficient code structure and optimization techniques.

## Gameplay Mechanics

The game features classic ping pong rules with modern enhancements. Players control paddles on opposite sides of the screen, trying to return the ball while preventing their opponent from scoring. The physics system creates unpredictable and exciting gameplay scenarios.

## Performance Optimization

Optimized the game for smooth 60 FPS performance across different devices, ensuring consistent gameplay experience regardless of hardware specifications.

This project highlights my versatility in game development and ability to create polished, enjoyable experiences using different development tools and languages.
