I developed My First Shooter, a stealth-focused shooter game that emphasizes tactical gameplay and strategic thinking. This project showcases my ability to create complex game mechanics and implement engaging stealth systems.

## Game Overview

My First Shooter is a tactical stealth shooter where players must carefully plan their approach, utilize cover systems, and execute precise shots while remaining undetected. The game focuses on quality mechanics over quantity of content.

## Key Features

**Stealth Mechanics**: Implemented comprehensive stealth systems including sound detection, line of sight mechanics, and environmental awareness that create tense, strategic gameplay.

**Tactical Combat**: Designed a combat system that rewards precision and planning over run-and-gun approaches, with realistic weapon mechanics and damage systems.

**Cover System**: Created an intuitive cover system that allows players to strategically position themselves and use the environment to their advantage.

**AI Behavior**: Developed intelligent enemy AI that responds to player actions, investigates disturbances, and creates dynamic gameplay scenarios.

## Technical Implementation

Built with Unity and C#, the game features advanced AI systems, efficient rendering for stealth mechanics, and responsive controls that support both keyboard/mouse and gamepad input.

## Gameplay Mechanics

The game emphasizes player agency through multiple approaches to each mission. Players can choose between aggressive stealth, complete avoidance, or tactical elimination strategies, each offering different challenges and rewards.

## Level Design

Designed levels that support multiple playstyles while maintaining clear objectives and progression. Each area provides opportunities for creative problem-solving and strategic thinking.

## Player Experience

My First Shooter offers a challenging but fair experience that rewards careful planning and execution. The game teaches players to think tactically and consider the consequences of their actions.

This project demonstrates my ability to create complex game systems and implement engaging mechanics that provide depth and replayability.
